# 0005：Phase 2 版號為 2.1.0，一次規劃、一次發布

- 狀態：已採用（2026-11-14，Phase 2 開始時）

## 背景
原本的版本政策是每完成一個 Phase 提升 minor 版本（Phase 2 = 1.1.0）。開始 Phase 2 前討論過三種切法：細分版本（v1.0.1 / v1.1.0 / v1.2.0）、維持單一版本、使用預發布標籤。

## 決策
- Phase 2 一次完整規劃，F2-01～F2-06 全部完成後才發布，版號由開發者指定為 **2.1.0**。
- 穩定性修正（F2-01）不另外發布 v1.0.1，與 Phase 2 一起發布。
- 開發期間 `Directory.Build.props` 與 `src/frontend/package.json` 即設為 2.1.0，代表目前開發中的目標版本；兩者仍必須一致。
- Phase 3 之後的版號於各 Phase 開始時再決定。
- `v1.0.0` 標籤標在 Phase 1 最後一個 commit（`93f2f05`），由開發者建立（Claude 的工作階段無法推送標籤）。

## 影響
- 1.0.0 與 2.1.0 之間沒有中間發布版本，也不使用 2.0.0。
- 各工作包在獨立分支開發，經開發者同意才合併到 `main`。
