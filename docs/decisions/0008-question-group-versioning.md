# 0008：題組版本化與不可變內容

- 狀態：已採用（2026-11-16）
- 相關：[docs/phase2/00-decisions.md](../phase2/00-decisions.md) 第 4 點；[02-database-design.md](../phase2/02-database-design.md)

## 背景

TOEIC 題目多半以題組出現（Part 3、4、6、7 一段內容配多題）。題目發布後若被直接修改，已完成的成績、解析與答對率統計都會失真；但題目仍需要能修正錯字或答案。

## 決策

1. **以題組為版本單位**：`QuestionGroup` 是固定身分；內容（文章、腳本、題目、選項、媒體）屬於 `QuestionGroupVersion`。單題的 Part 1、2、5 也是只有一題的題組。
2. **狀態只往前**：`Draft` → `Published` → `Retired`。每個題組最多一個草稿（資料庫篩選唯一索引）、最多一個已發布版本（Domain 規則；發布會更新題組本身，以 `rowversion` 讓並行發布只有一個成功）。
3. **修改已發布內容**：複製成新的草稿版本，修改後發布；發布時舊版本在同一交易中改為 `Retired`。
4. **不刪除**：已發布或停用的版本、已上傳的媒體、完成的作答都不能刪除；只有草稿可以刪除。
5. **雙重防護**：Domain 方法拒絕修改非草稿內容；Infrastructure 的 `ImmutableContentInterceptor` 在 `SaveChanges` 時再檢查一次，防止程式錯誤繞過 Domain。
6. **作答快照只存參照**：`AttemptQuestionSnapshot` 記錄題組版本、題目、順序與當時的正確答案，不複製文字內容；因為被引用的版本不可變，參照即可重現當時的題目。

## 理由

- 成績與解析永遠對應作答當時的內容，且不必複製大量文字。
- 題組為單位符合 TOEIC 的出題與審核方式（同一段文章的題目一起修改、一起發布）。
- 資料庫索引與 SaveChanges 防護讓「不可變」不只依賴程式紀律。

## 影響

- 題庫管理介面（F2-03）需要「建立新版本」「比較版本」「停用」等操作，而不是直接編輯。
- 統計題目答對率時，以題組身分（`QuestionGroupId`）或題目版本為單位需在 F2-06 決定顯示方式；資料兩者都保留。
- 已發布試卷引用的是特定版本；題組改版後，舊試卷仍使用舊版本，新試卷才會用新版本。
