# 0007：練習與模擬考共用 `ExamAttempt` 作答模型

- 狀態：已採用（2026-11-16）
- 相關：[docs/phase2/00-decisions.md](../phase2/00-decisions.md) 第 3、5、6 點；[02-database-design.md](../phase2/02-database-design.md)

## 背景

Phase 2 同時有練習（自選 Part、主題、題數，可隨時結束）、完整模擬考（200 題、聽力接閱讀、伺服器計時）與音檔補齊前的閱讀測驗（Part 5–7、75 分鐘）。三者都需要：保存當時的題目版本與正確答案、自動存答、多分頁以最後儲存為準、交卷冪等、成績不重算、記錄做過的題目。

可以為練習另建 `PracticeSession`，或與模擬考共用一個作答模型。

## 決策

共用 `ExamAttempt`、`AttemptQuestionSnapshot`、`AttemptAnswer`，以 `Mode`（`Practice` / `MockExam` / `ReadingTest`）區分。各模式的差異集中在 Domain 的規則物件（`AttemptModeRules`）：

| 規則 | 練習 | 模擬考 | 閱讀測驗 |
|---|---|---|---|
| 題目來源 | 依篩選條件挑選已發布題組版本 | 已發布試卷（`FullTest`） | 已發布試卷（`ReadingOnly`） |
| 計時 | 不限時，只記錄約略作答時間 | 聽力 = 音檔總長；閱讀 75 分鐘 | 閱讀 75 分鐘 |
| 段落 | 無 | 聽力 → 閱讀，不能返回 | 只有閱讀 |
| 結束方式 | 交卷或放棄 | 交卷或逾時自動交卷 | 交卷或逾時自動交卷 |
| 即時顯示答案 | 可設定（每題作答後顯示） | 不可 | 不可 |

## 理由

- 快照、存答、交卷、計分與成績報告只寫一次，三種模式行為一致，測試也集中。
- 「做過的題目」與題目答對率可以直接從同一組資料表統計，不必合併兩種來源。
- 差異大多是規則參數，放在規則物件比分成兩套資料表更容易維護。

## 影響

- `ExamPaperId`、聽力相關時間欄位在練習模式為 NULL，由 Domain 驗證各模式必填欄位。
- 歷史成績列表需要依 `Mode` 篩選與顯示。
- 若日後練習需要與模擬考差異很大的欄位，再評估拆表；目前沒有這種需求。
